Retrieval

StockRAG

Python · SEC EDGAR XBRL · BM25 + vector (RRF) · cross-encoder · ChromaDB · LangChain · Ragas · GitHub Actions
AccomplishedEliminated fabricated figures from an AI financial research assistant answering questions over 10-K and 10-Q filings.
Measured byA CI eval harness that blocks any merge regressing citation coverage, plus a hard rule: no citation, no answer — the system refuses instead.
By doingComputing Piotroski, Novy-Marx and Fama-French factors deterministically from XBRL so no model touches an arithmetic path, and fusing BM25 with vector retrieval via RRF, rescored by a cross-encoder.
Evaluation

SLM JSON Benchmark

Python · Ollama · Pydantic · open-weight LLaMA-family models · GitHub Pages
AccomplishedIdentified a 3B model matching a 7B model's answer quality at ~2.5× throughput and half the memory — and found temperature 0.7 dropping schema validity from 100% to 80%.
Measured by40 prompts across 5 categories, scored on first-try JSON validity, retry recovery, answer quality, TTFT, tokens/sec and peak memory.
By doingBuilding an Ollama-based benchmark harness with Pydantic schema validation, published as a live leaderboard anyone can re-run.
